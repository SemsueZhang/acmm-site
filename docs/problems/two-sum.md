# Two Sum

## 题目概述

给定一个整数数组 `nums` 和一个目标值 `target`, 在数组中找出和为 `target` 的两个元素并返回它们的下标。

## 核心思路

使用哈希表记录已经遍历过的元素及其下标。遍历到当前值 `x` 时, 查询 `target - x` 是否已出现:

- 若已出现, 直接返回两个下标
- 若未出现, 记录当前值及其下标

该方法将时间复杂度优化到 $O(n)$, 空间复杂度为 $O(n)$。

## 复杂度

- 时间复杂度: $O(n)$
- 空间复杂度: $O(n)$

## 代码框架

```text
for i in range(len(nums)):
    x = nums[i]
    if target - x in map:
        return [map[target - x], i]
    map[x] = i
```

## 易错点

- 哈希表应保存下标, 不是出现次数
- 返回顺序不重要, 但必须是有效下标
