# 字符串算法

字符串算法看似各不相同，其实反复在做一件事：**把已经比较过的字符关系保存下来，下一步尽量复用，而不是从头比较**。

例如，KMP 保存前缀与后缀的重合，Manacher 保存回文区间的对称信息，Z 函数保存后缀与整串前缀的重合，后缀数组则把所有后缀排成有序序列。学习时最值得追问的不是“模板有几行”，而是：旧信息为什么足以确定一部分新答案？剩下的暴力扩展为什么总量可控？

## NOIP 提高级主线

1. [字符串基础](basics.md)：子串、子序列、前缀、后缀、LCP、Border 与周期等统一术语。
2. [KMP](kmp.md)：从一次具体失配推导前缀函数与线性匹配。
3. [Border 与周期](border-period.md)：沿前缀函数链解决循环节和前后缀问题。
4. [Trie](trie.md)：把许多字符串的公共前缀合并成一棵树。
5. [字符串哈希](hash.md)：用可组合的数值指纹快速比较子串。
6. [Manacher](manacher.md)：复用最右回文区间，线性求奇偶回文半径。

## NOI 级拓展

- [Z 函数（扩展 KMP）](z-function.md)：求每个后缀与整串的最长公共前缀。
- [后缀数组](suffix-array.md)：对所有后缀排序，并用 LCP 数组处理重复子串问题。

## 如何阅读一篇算法讲义

每篇正文按以下节奏组织：先用真实问题说明朴素方法浪费在哪里，再定义算法维护的信息，证明转移和复杂度，最后用模板题或经典题展示这些信息怎样参与解题。代码统一使用 C++17 和 0-based 下标；若题目输出使用 1-based，会在对应位置明确转换。
