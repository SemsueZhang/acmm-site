# 字符串基础

字符串算法最容易出现的错误，往往不是算法本身，而是“子串”和“子序列”、“前缀”和“真前缀”等术语没有分清。本页统一后续章节使用的记号。

## 1. 字符串、子串与子序列

设字符串 $s=s_0s_1\cdots s_{n-1}$，长度记为 $|s|=n$。

- **子串** `s[l..r]`：保留一段连续位置，长度为 $r-l+1$。
- **子序列**：删除任意若干字符后保持相对顺序，位置不必连续。
- **前缀**：从位置 0 开始的子串；**后缀**：在位置 $n-1$ 结束的子串。
- **真前缀/真后缀**：不等于原串本身的前缀/后缀，空串是否计入要看上下文。

以 `s="abaca"` 为例：`"bac"` 是子串，`"aaa"` 是子序列但不是子串，`"aba"` 是前缀，`"aca"` 是后缀。

!!! warning "下标约定"
    本章代码使用 0-based 下标和闭区间 `[l,r]`。空区间写作 `l>r`。读其他资料时先确认它使用的是 0-based 还是 1-based，再比较公式。

## 2. 字典序

比较两个字符串时，从左向右找第一个不同字符，较小字符所在字符串更小；若一个串是另一个串的前缀，较短者更小。

例如：

```text
"app" < "apple" < "apply" < "banana"
```

字典序使字符串可以排序和二分。后缀数组就是把同一个字符串的所有后缀按字典序排列。

## 3. LCP、LCS 与匹配

- $\operatorname{lcp}(a,b)$：两个字符串的最长公共前缀长度。
- $\operatorname{lcs}(a,b)$：两个字符串的最长公共后缀长度，本章不使用它表示“最长公共子序列”。

`"abandon"` 与 `"abacus"` 的 LCP 是 `"aba"`，长度为 3。许多字符串算法都在批量求某种 LCP：Z 函数求 $s$ 与每个后缀的 LCP，后缀数组的 `height` 求字典序相邻后缀的 LCP。

## 4. Border 与周期

若非空字符串 $x$ 同时是 $s$ 的真前缀和真后缀，则 $x$ 是 $s$ 的一个 **Border**。

`s="ababab"` 的 Border 有 `"ab"` 和 `"abab"`。长度 4 的 Border 允许前缀和后缀发生重叠；Border 的定义不要求两段互不相交。

正整数 $p$ 是 $s$ 的一个**周期**，当且仅当对所有 $0\le i<n-p$ 都有 $s_i=s_{i+p}$。`"ababab"` 的周期包括 2、4、6；周期不要求整除串长，只有整除时才能把字符串完整拆成若干相同块。

Border 与周期的联系是：

$$
p\text{ 是周期}\quad\Longleftrightarrow\quad s[0..n-p-1]=s[p..n-1].
$$

等号两侧正是一段长度 $n-p$ 的前缀和后缀，因此“长度 $n-p$ 的 Border”与“周期 $p$”等价。这个简单关系是 KMP 处理循环节问题的基础。

## 5. 字符集与存储选择

字符集大小记为 $|\Sigma|$。只含小写字母时 $|\Sigma|=26$，可以用定长数组保存转移；若字符可能是任意单词或整数，通常要先离散化，或用 `map`/`unordered_map`。

| 任务 | 直接方法 | 数据量大时的工具 |
| --- | --- | --- |
| 找一个模式串的所有出现位置 | 逐起点比较 $O(nm)$ | KMP $O(n+m)$ |
| 判断任意两个子串是否相等 | 逐字符比较 | 字符串哈希 |
| 查询大量单词的公共前缀 | 逐个扫描单词 | Trie |
| 求最长回文子串 | 枚举中心 $O(n^2)$ | Manacher $O(n)$ |
| 比较大量后缀 | 每次直接比较 | 后缀数组（拓展） |

## 6. 从数据范围选择算法

若 $n\le 2000$，$O(n^2)$ 的中心扩展或 DP 往往足够；若 $n$ 达到 $10^5$ 或 $10^6$，通常需要线性或 $O(n\log n)$。但复杂度相同不代表功能相同：KMP 是确定性匹配并提供 Border 链，哈希适合灵活比较任意子串但存在碰撞风险。先看题目要什么信息，再选算法。

## 常见误区

- 把子序列当成连续子串。
- 认为 Border 的前缀和后缀不能重叠。
- 认为周期必须整除串长。
- 同一份代码里混用闭区间和半开区间。
- 只比较算法复杂度，不比较算法输出的信息和正确性保证。
