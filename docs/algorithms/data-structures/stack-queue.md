# 栈与队列

栈与队列是线性表上的访问约束结构, 常用于模拟过程与搜索。

## 核心概念

- 栈: 后进先出(LIFO)
- 队列: 先进先出(FIFO)
- 双端队列: 两端均可插入删除

## 典型应用

- 栈: 括号匹配, 表达式求值, 单调栈
- 队列: BFS, 任务调度, 滑动窗口
- 双端队列: 单调队列, 0-1 BFS

## 常见模板

- 栈模拟递归
- 队列层序遍历
- 单调栈维护最近更大/更小元素

## 复杂度

- 入栈/出栈: $O(1)$
- 入队/出队: $O(1)$

## 易错点

- 注意空栈与空队的边界处理
- 单调结构需在入队/入栈时维护单调性

## 练习方向

- 括号序列判定与最短补全
- 滑动窗口最值
- 柱状图最大矩形
