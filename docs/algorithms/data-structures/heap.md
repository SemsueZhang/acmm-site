# 堆

堆是维护最值的完全二叉树结构, 常用于优先队列。

## 核心概念

- 大根堆: 父节点 >= 子节点
- 小根堆: 父节点 <= 子节点
- 用数组表示: 对于下标 i, 子节点为 2i 和 2i+1

## 常见操作

- 插入: 末尾插入后上浮
- 删除堆顶: 末尾替换后下沉
- 取最值: $O(1)$

## 复杂度

- 插入/删除: $O(\log n)$
- 建堆: $O(n)$

## 典型应用

- Top K 问题
- 合并 K 个有序序列
- 最短路中的优先队列

## 易错点

- 注意 0/1 下标的子节点公式
- 堆不支持快速删除中间元素

## 练习方向

- 动态维护第 K 大
- 数据流中位数
- 多路归并
