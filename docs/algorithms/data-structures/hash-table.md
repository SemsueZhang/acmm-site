# 哈希表

哈希表通过散列函数将键映射到桶, 以空间换时间实现快速查找。

## 核心概念

- 哈希函数: 将键映射到固定范围
- 冲突: 不同键映射到同一位置
- 处理冲突: 链地址法, 开放定址

## 常见操作

- 插入/查找/删除: 平均 $O(1)$
- 统计频次, 记录位置, 去重

## 使用场景

- 两数之和
- 频率统计与众数
- 缓存与去重

## 易错点

- 选择合适的键, 避免不必要的字符串拼接
- 注意负数或大数作为键的映射方式
- 可能存在最坏 $O(n)$, 但通常可接受

## 练习方向

- 哈希 + 双指针
- 哈希集合判重
- 哈希映射缓存中间结果
