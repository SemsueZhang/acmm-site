# 并查集

并查集用于维护不相交集合, 支持合并与查询同属关系。

## 核心概念

- parent 数组表示父节点
- 路径压缩降低查询复杂度
- 按秩合并保持树高

## 基本操作

- find(x): 查找根
- union(a, b): 合并两个集合

## 复杂度

- 近似 $O(\alpha(n))$, 可视为常数

## 典型应用

- 连通分量计数
- Kruskal 最小生成树
- 动态连通性判断

## 易错点

- 合并时要先找根
- 路径压缩可写成递归或迭代
