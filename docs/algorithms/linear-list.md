# 线性表

线性表是一类按顺序组织的数据结构, 元素之间是一对一的线性关系。常见实现包括数组与链表。

## 核心概念

- 逻辑结构: 线性, 每个元素至多有一个前驱与一个后继
- 物理结构: 顺序存储(数组)或链式存储(链表)

## 数组

特点是连续存储与随机访问快。

- 优点: 支持 $O(1)$ 访问, 便于二分与前缀和
- 缺点: 插入删除可能需要移动大量元素
- 常见操作复杂度: 访问 $O(1)$, 插入/删除 $O(n)$

## 链表

特点是通过指针连接, 插入删除灵活。

- 优点: 插入删除可达 $O(1)$
- 缺点: 访问需要遍历, 为 $O(n)$
- 变体: 单链表, 双链表, 循环链表

## 栈与队列

栈与队列是线性表上的访问约束。

- 栈: 先进后出(LIFO), 典型应用是括号匹配与表达式求值
- 队列: 先进先出(FIFO), 典型应用是 BFS 与任务调度
- 双端队列: 支持两端插入删除

## 常见应用

- 线性扫描与双指针
- 前缀和与差分
- 单调栈与单调队列

## 练习方向

- 链表反转, 合并有序链表
- 栈模拟与区间匹配
- 队列在层序遍历中的应用
