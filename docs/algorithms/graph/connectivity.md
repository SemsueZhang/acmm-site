# 强连通分量、割点与割边

这三类算法都使用 DFS 时间戳。`dfn[u]` 是首次访问 $u$ 的时间，`low[u]` 表示从 $u$ 的 DFS 子树出发，通过若干树边并至多一条返祖边能到达的最小 `dfn`。两者含义必须先理解再写模板。

## 强连通分量（SCC）

有向图中互相可达的最大顶点集合称为强连通分量。把每个 SCC 缩成一个点后，得到的图一定是 DAG，否则环上的分量本应合并。

### Tarjan 算法

DFS 时把未归属 SCC 的点压栈：

- 树边 `u→v`：递归后用 `low[v]` 更新 `low[u]`。
- 指向栈内点的边 `u→v`：用 `dfn[v]` 更新。
- 若 `dfn[u]==low[u]`，$u$ 是一个 SCC 的根，持续弹栈直到 $u$。

```cpp
void tarjan(int u) {
    dfn[u] = low[u] = ++timer;
    st.push_back(u);
    inStack[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (inStack[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (low[u] == dfn[u]) {
        ++sccCount;
        while (true) {
            int v = st.back(); st.pop_back();
            inStack[v] = false;
            component[v] = sccCount;
            if (v == u) break;
        }
    }
}
```

例：`1→2→3→1` 与 `3→4,4→5,5→4` 形成两个 SCC `{1,2,3}`、`{4,5}`，缩点后只有前者指向后者。

## 无向图的桥

删除某条边后连通分量增加，这条边是桥。DFS 树边 $(u,v)$ 是桥，当且仅当：

$$
low[v] > dfn[u].
$$

这说明 $v$ 的子树没有返祖边回到 $u$ 或更早祖先。无向图必须按**边编号**跳过父边；有重边时若只写 `v==parent`，会错误地把两条平行边都跳过。

## 无向图的割点

删除某个点及其相邻边后连通分量增加，该点是割点。

- 非根节点 $u$：存在孩子 $v$ 满足 `low[v] >= dfn[u]`。
- DFS 根：至少有两个 DFS 树孩子。

等号与桥不同：子树只能回到 $u$ 时，删掉 $u$ 仍会断开，所以用 `>=`。

### 手算例题

三角形 `1-2-3-1` 再接边 `3-4`。三角形边都不是桥，因为存在返祖路径；`3-4` 是桥。删除点 3 后，点 4 与 `{1,2}` 分离，所以 3 是割点。

## 复杂度与错误

三种 Tarjan 算法均为 $O(n+m)$，但“有向 SCC”和“无向割点桥”的 `low` 更新规则不可混用。

## 真实题目如何对应

- [洛谷 P3387【模板】缩点](https://www.luogu.com.cn/problem/P3387)：先求 SCC，把分量权值相加并建立缩点 DAG，再按拓扑顺序做最长路 DP。难点不止 Tarjan，还包括缩点后的状态重建。
- [洛谷 P3388【模板】割点](https://www.luogu.com.cn/problem/P3388)：在无向图中分别处理 DFS 根与非根，判断 `low[child] >= dfn[u]`；同一个割点可能被多个孩子发现，输出前必须去重。

练习时应为 SCC 与割点分别写模板，不要试图通过改一个比较符号复用同一 DFS。二者对返祖边、栈和父边的处理语义不同。

- SCC 中只用指向**栈内点**的边更新。
- 无向图返祖边用 `dfn[v]` 更新，并按边编号排除当前父边。
- 图不连通时要从每个未访问点启动 DFS。
- SCC 缩点建边后可能有重边；计数或拓扑处理时按题意去重。
