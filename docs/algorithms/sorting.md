# 排序算法

排序是算法学习的核心起点, 也是理解复杂度与稳定性的最佳入口。

## 为什么重要

- 几乎所有算法题都与排序或排序思想相关
- 便于理解分治、比较、稳定性等概念
- 是后续二分、贪心与数据结构优化的基础

## 概念要点

- 稳定性: 相等元素的相对顺序是否保持
- 原地排序: 是否使用额外数组
- 比较排序下界: 一般为 $O(n \log n)$

## 常见排序对比

| 算法 | 平均复杂度 | 是否稳定 | 是否原地 | 适用场景 |
| --- | --- | --- | --- | --- |
| 冒泡排序 | $O(n^2)$ | 稳定 | 是 | 教学与理解稳定性 |
| 选择排序 | $O(n^2)$ | 不稳定 | 是 | 了解交换策略 |
| 插入排序 | $O(n^2)$ | 稳定 | 是 | 数据量小或近乎有序 |
| 归并排序 | $O(n \log n)$ | 稳定 | 否 | 需要稳定性与可预测性能 |
| 快速排序 | $O(n \log n)$ | 不稳定 | 是 | 通用排序首选 |

## 训练建议

- 先掌握插入与归并, 再深入快速排序
- 理解分治思想与递归边界
- 会写排序后再看排序的应用题
