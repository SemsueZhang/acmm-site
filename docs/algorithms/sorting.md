# 排序算法

排序不仅是把数排好。它会把“任意位置关系”变成“相邻关系”，从而支持二分、双指针、贪心和离散化。

## 关键概念

- **稳定性**：关键字相等的元素，排序后相对顺序不变。
- **原地排序**：只使用 $O(1)$ 或递归栈级别的额外空间。
- **比较排序下界**：一般比较模型中，排序最坏至少需要 $\Omega(n\log n)$ 次比较；计数/桶/基数排序利用键值性质，不受这一限制。

| 算法 | 时间复杂度 | 额外空间 | 稳定 |
| --- | --- | --- | --- |
| 冒泡/选择/插入 | $O(n^2)$ | $O(1)$ | 冒泡、插入稳定 |
| 归并排序 | $O(n\log n)$ | $O(n)$ | 是 |
| 快速排序 | 平均 $O(n\log n)$，最坏 $O(n^2)$ | 平均 $O(\log n)$ 栈 | 否 |
| 堆排序 | $O(n\log n)$ | $O(1)$ | 否 |
| 计数排序 | $O(n+K)$ | $O(K)$ | 可稳定 |
| 基数排序 | $O(d(n+K))$ | $O(n+K)$ | 是（每轮必须稳定） |

## 插入排序：小规模与近乎有序

维护前缀 `[0,i)` 已有序，把 `a[i]` 插到正确位置。若数组近乎有序，移动次数少，性能很好。

```cpp
for (int i = 1; i < n; ++i) {
    int x = a[i], j = i - 1;
    while (j >= 0 && a[j] > x) {
        a[j + 1] = a[j];
        --j;
    }
    a[j + 1] = x;
}
```

注意条件用 `>` 而非 `>=` 才能保持稳定。

### 冒泡与选择排序对照

对 `4 2 3 1`：冒泡排序比较相邻逆序对并交换，第一趟把最大值 4 推到末尾；选择排序在未排序区找最小值 1，与区首 4 交换。二者都做 $O(n^2)$ 次量级比较，但性质不同：

- 冒泡只交换相邻元素，相等元素不交换时稳定；若一趟没有交换可提前结束。
- 选择排序每趟只做一次关键交换，但远距离交换可能跨过相等元素，因此通常不稳定。

这两种算法主要用于理解不变量；大数据实战不应手写它们替代 `std::sort`。

## 归并排序：先排两半，再线性合并

将数组一分为二，递归排序，然后用双指针合并。每层合并总工作量 $O(n)$，共 $O(\log n)$ 层，因此总时间 $O(n\log n)$。归并过程还能统计逆序对，详见[分治](foundations/divide-conquer-sweep.md)。

## 快速排序：按基准分区

选择基准 `pivot`，把较小元素放左边、较大元素放右边，再递归两侧。随机选择基准可降低被特殊数据卡到 $O(n^2)$ 的风险。实战通常直接使用 `std::sort`，它保证 $O(n\log n)$ 量级的最坏复杂度并做了多种常数优化。

## 非比较排序

### 计数排序例题

把 `3 1 2 1 3` 排序，统计频次 `cnt[1]=2,cnt[2]=1,cnt[3]=2`，再按值输出 `1 1 2 3 3`。当值域 $K$ 与 $n$ 同量级时为 $O(n+K)$；值域达到 $10^9$ 时不可直接开桶。

桶排序把一个值域段而非单个值放进一个桶，桶内再排序；适合数据分布较均匀的数值。最坏情况下所有元素落入同一桶，性能取决于桶内算法，不能无条件宣称线性。

### 基数排序

依次按个位、十位、百位……进行**稳定排序**。例如 `21,13,12` 先按个位得到 `21,12,13`，再稳定地按十位得到 `12,13,21`。若某一轮不稳定，上一轮建立的低位顺序会被破坏。

```cpp
// 非负十进制整数的 LSD 基数排序
for (long long exp = 1; maximum / exp > 0; exp *= 10) {
    vector<int> count(10), output(a.size());
    for (int x : a) ++count[(x / exp) % 10];
    for (int d = 1; d < 10; ++d) count[d] += count[d - 1];
    for (int i = (int)a.size() - 1; i >= 0; --i) {
        int digit = (a[i] / exp) % 10;
        output[--count[digit]] = a[i]; // 倒序放置保证稳定
    }
    a.swap(output);
    if (exp > maximum / 10) break; // 防止 exp *= 10 溢出
}
```

若最大数有 $d$ 位、基数为 $K$，时间 $O(d(n+K))$，额外空间 $O(n+K)$。负数需分离处理或改变符号位映射。

## 堆排序

先 $O(n)$ 建大根堆；把堆顶最大值与当前末尾交换，缩小堆范围并下沉新堆顶。共做 $n-1$ 次 $O(\log n)$ 下沉，总时间 $O(n\log n)$、额外空间 $O(1)$。它最坏复杂度稳定，但不稳定，且缓存局部性通常不如快速排序。

## 自定义排序例题：拼接最大数

给定若干非负整数字符串，调整顺序使拼接结果最大。比较器应判断 `a+b > b+a`，而不是只比较数值或首字符。

```cpp
sort(s.begin(), s.end(), [](const string& a, const string& b) {
    return a + b > b + a;
});
if (s[0] == "0") cout << 0;
else for (const string& x : s) cout << x;
```

例如 `3,30,34`：`34+3 > 3+34`，且 `3+30 > 30+3`，答案 `34330`。比较器必须满足严格弱序；不能写 `>=`。

## 常见错误

- 认为 `std::sort` 稳定；需要稳定性时使用 `stable_sort`。
- 自定义比较器在相等时返回 `true`，破坏严格弱序，行为未定义。
- 桶排序没有考虑负数、值域和内存。
- 手写快排时大量相等元素导致死循环或极端不平衡。
