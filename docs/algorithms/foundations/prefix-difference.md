# 前缀和、差分与离散化

三者都在做同一件事：**换一种表示，让大量重复操作可以复用**。

## 一维前缀和

定义 $s_i=\sum_{k=1}^{i}a_k$，并令 $s_0=0$。则闭区间 $[l,r]$ 的和为：

$$
\sum_{k=l}^{r}a_k=s_r-s_{l-1}.
$$

### 例题：静态区间和

数组 `2 1 4 3 5` 的前缀和为 `0 2 3 7 10 15`。查询 $[2,4]$ 时计算 $10-2=8$，无需重新遍历区间。

```cpp
vector<long long> pre(n + 1, 0);
for (int i = 1; i <= n; ++i) pre[i] = pre[i - 1] + a[i];
cout << pre[r] - pre[l - 1] << '\n';
```

预处理 $O(n)$，每次查询 $O(1)$。前缀和可能远大于单个元素，应优先用 `long long`。

## 二维前缀和

令 $s_{i,j}$ 是矩形 $(1,1)$ 到 $(i,j)$ 的和。由容斥：

$$
s_{i,j}=a_{i,j}+s_{i-1,j}+s_{i,j-1}-s_{i-1,j-1}.
$$

查询左上角 $(x_1,y_1)$、右下角 $(x_2,y_2)$ 的矩形：

$$
s_{x_2,y_2}-s_{x_1-1,y_2}-s_{x_2,y_1-1}+s_{x_1-1,y_1-1}.
$$

减去上方和左方时，左上重叠区被减了两次，因此要加回来一次。

## 差分

差分是前缀和的逆操作。令 $d_1=a_1$，$d_i=a_i-a_{i-1}$。对区间 $[l,r]$ 全部加 $x$，只需：

```cpp
d[l] += x;
d[r + 1] -= x;
```

最后对 `d` 求前缀和即可恢复数组。原因是从 $l$ 开始贡献 $x$，到 $r+1$ 抵消。

### 例题：批量铺地毯

初始长度为 5 的数组全为 0，依次对 $[2,4]$ 加 3、对 $[3,5]$ 加 2。差分数组变化后为 `0,3,2,0,-3,-2`（展示 $1..6$），前缀累加得到 `0,3,5,5,2`。

```cpp
vector<long long> diff(n + 2);
for (auto [l, r, x] : operations) {
    diff[l] += x;
    diff[r + 1] -= x;
}
for (int i = 1; i <= n; ++i) {
    diff[i] += diff[i - 1];
    cout << diff[i] << " \n"[i == n];
}
```

差分适合“修改很多次，最后统一询问”。若修改与查询交错，需要树状数组或线段树。

## 离散化

当坐标值很大但实际只出现少量位置时，把这些值排序去重，用排名代替原值。离散化只保留**大小关系和相等关系**，不保留相邻距离。

### 例题：动态统计不大于 $x$ 的元素

值可能达到 $10^9$，但只有 $n\le2\times10^5$ 个。把所有可能出现的值放入 `xs`：

```cpp
sort(xs.begin(), xs.end());
xs.erase(unique(xs.begin(), xs.end()), xs.end());
int id = lower_bound(xs.begin(), xs.end(), value) - xs.begin() + 1;
```

随后可在编号 $1..|xs|$ 上使用树状数组。若题目关心区间长度，例如扫描线覆盖长度，不能简单把坐标看成连续编号，必须使用原坐标差 `xs[i+1]-xs[i]`。

## 常见错误

- 混用 0 下标和 1 下标，错写成 `pre[r]-pre[l]`。
- 忘记给 `r+1` 或二维边界多开一行一列。
- 二维容斥中把左上角重复区域的符号写错。
- 离散化后误以为相邻编号对应原坐标相差 1。
