# 复杂度、枚举与模拟

## 1. 先读数据范围

算法复杂度描述输入规模增长时，操作次数怎样增长。竞赛中常把约 $10^8$ 次简单运算看作 C++ 一秒的粗略上限，但机器、常数和访存方式都会影响实际速度，不能把它当定理。

| $n$ 的量级 | 常见可行复杂度 |
| --- | --- |
| $n\le 20$ | $O(2^n)$、$O(n!)$（后者通常还要更小） |
| $n\le 500$ | $O(n^3)$ 可能可行 |
| $n\le 5000$ | $O(n^2)$ 可能可行 |
| $n\le 2\times10^5$ | 通常需要 $O(n\log n)$ 或 $O(n)$ |
| $n\ge 10^7$ | 通常只能接近 $O(n)$，还要留意内存 |

连续循环复杂度相加，嵌套循环通常相乘；但要看变量实际移动次数：双指针虽然写成嵌套循环，两个指针都只单向移动，仍可能是 $O(n)$。

空间也要估算。一个 `int` 通常占 4 字节，`long long` 通常占 8 字节；`int a[10000000]` 已约占 40 MB。递归还会使用调用栈。

## 2. 枚举：不重不漏地缩小范围

枚举不是“无脑暴力”，而是选定一组足以唯一决定答案的变量，只枚举这些变量，其余信息直接计算。

### 例题：两数之和

给定 $n$ 个整数和目标 $T$，判断是否存在两个不同位置 $i,j$，使 $a_i+a_j=T$。

直接枚举 $(i,j)$ 是 $O(n^2)$。若先排序，枚举左指针 $l$，右指针 $r$ 可由和的大小决定移动：

- 和太小，只能增大 $l$；
- 和太大，只能减小 $r$；
- 每个指针最多移动 $n$ 次，总复杂度 $O(n\log n)$，其中排序占主导。

```cpp
sort(a.begin(), a.end());
int l = 0, r = (int)a.size() - 1;
while (l < r) {
    long long sum = 1LL * a[l] + a[r];
    if (sum == target) { cout << "Yes\n"; return 0; }
    if (sum < target) ++l;
    else --r;
}
cout << "No\n";
```

这里的关键不变量是：移动后被排除的数不可能再与区间内任何数构成目标和。

## 3. 模拟：把规则变成状态机

模拟题先定义“完整状态”，再逐条实现转移。推荐把方向、坐标、时间等有明确含义的数据放进变量或结构体，不要用大量互相影响的分支硬拼。

### 例题：机器人行走

机器人初始位于 $(0,0)$，面向北。命令 `L`/`R` 原地转向，`F k` 前进 $k$ 步，求最终坐标。

用 `dir=0,1,2,3` 表示北、东、南、西，方向向量为：

```cpp
int dx[4] = {0, 1, 0, -1};
int dy[4] = {1, 0, -1, 0};

// 左转加 3、右转加 1，再模 4，避免为负数。
if (op == 'L') dir = (dir + 3) % 4;
else if (op == 'R') dir = (dir + 1) % 4;
else { x += dx[dir] * k; y += dy[dir] * k; }
```

每条命令 $O(1)$，共 $q$ 条命令，时间 $O(q)$，额外空间 $O(1)$。

## 4. 递推、递归与倍增

- **递推**：按已知顺序从小状态算大状态，例如斐波那契数列。
- **递归**：函数调用自身，适合树、分治与搜索；必须明确终止条件。
- **倍增**：预处理“走 $2^k$ 步后的结果”，再按二进制拆分步数。LCA、快速幂都使用这一思想。

例如要沿父指针向上走 $13=8+4+1$ 步，只需依次使用 $2^3,2^2,2^0$ 的跳跃信息，而不是走 13 次。

## 常见错误

- 只看循环层数，不看循环变量总共移动多少次。
- 用 `int` 存操作次数、乘积或距离导致溢出。
- 枚举排列时没有处理重复元素，造成重复计算。
- 模拟中边读边改共享状态，违反“本轮同时发生”的规则；这类题应从旧数组转移到新数组。
- 递归缺少边界，或深度达到 $10^5$ 导致栈溢出。
