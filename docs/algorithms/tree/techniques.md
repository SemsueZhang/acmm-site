# 树上综合算法

本页覆盖提高组常见的树的直径、重心、DFS 序、子树和、倍增与树上差分。它们共同利用了树上两点间路径唯一这一性质。

## 树的直径

树上最长简单路径称为直径。

### 两次 DFS/BFS

边权非负时，从任意点 $s$ 出发找到最远点 $a$；再从 $a$ 出发找到最远点 $b$，路径 $a\to b$ 是一条直径。无权树用 BFS，带非负权树用 DFS 累加距离即可，因为路径唯一。

例：链 `1-2-3-4` 再接 `2-5`。从 1 最远可到 4，再从 4 最远到 5，直径 `4-3-2-5` 长 3。

若边权可为负，“最远端点”结论与空路径定义需要重新讨论；这时常用树形 DP。

### 树形 DP 求直径

`down[u]` 表示从 $u$ 向子树走的最长链。对每个孩子 $v$，用最大的两条 `down[v]+w` 更新经过 $u$ 的直径。

## 树的重心

删除某点后会得到若干连通块。若最大连通块大小最小，该点是重心；等价地，重心删除后每个连通块大小都不超过 $n/2$。

根定为 1，删除 $u$ 后，孩子 $v$ 方向块大小为 `size[v]`，父亲方向大小为 `n-size[u]`：

```cpp
void dfsCenter(int u, int p) {
    size[u] = 1;
    int largest = 0;
    for (int v : g[u]) if (v != p) {
        dfsCenter(v, u);
        size[u] += size[v];
        largest = max(largest, size[v]);
    }
    largest = max(largest, n - size[u]);
    if (largest < best) { best = largest; centers = {u}; }
    else if (largest == best) centers.push_back(u);
}
```

一棵树有一个或两个重心。

## DFS 序与子树和

用 `tin/tout` 把每棵子树映射到连续区间。若节点权值会单点修改、需查询子树和，把权值放到 `a[tin[u]]`，用树状数组维护 `[tin[u],tout[u]]` 即可。

## 树上差分

### 点差分：路径上的点都加 1

对每条路径 $(u,v)$：

```text
diff[u] += 1
diff[v] += 1
diff[lca(u,v)] -= 1
diff[parent(lca(u,v))] -= 1
```

最后后序累加 `diff[u] += sum(diff[child])`，所得 `diff[x]` 就是经过点 $x$ 的路径数。

为什么要减 LCA 一次、LCA 父亲一次？$u,v$ 的贡献向上汇合后 LCA 会收到两份；减一使 LCA 保留一份，再在其父亲处减一阻止贡献继续向上。

### 边差分：路径上的边都加 1

```text
diff[u] += 1
diff[v] += 1
diff[lca(u,v)] -= 2
```

后序累加后，`diff[x]` 表示边 `(parent[x],x)` 被经过多少次。

### 例题

树边 `1-2,1-3,2-4,2-5`，路径 `(4,3)` 与 `(5,3)`。两条路径都经过点 1、2、3；点 4、5 各一次。点差分批量标记后一次后序汇总，就能在线性时间得到全部计数，而不是逐条路径走。

## 倍增的其他用途

除 LCA 外，倍增还能回答“向上走 $k$ 步”“路径上第 $k$ 个点”，或维护跳跃段的最大边权。合并信息时必须保证运算满足结合性，并注意跳跃方向。

## 易错点

- 直径两次搜索法用于一般图或负权树。
- 求重心时漏掉父亲方向的 `n-size[u]`。
- DFS 序把 `tout` 记成退出时再次加一，导致子树区间不连续。
- 点差分和边差分公式混用。
- 多条询问标记完后没有按后序汇总。
