# 最近公共祖先(LCA)

LCA 用于查询两节点在树中的最近公共祖先, 是树上路径问题的基础。

## 常见方法

- 朴素上跳: 逐层上移, $O(n)$
- 二分提升: 预处理倍增表, 查询 $O(\log n)$
- Euler 序 + RMQ: 预处理后 $O(1)$ 查询

## 倍增思路

1. 预处理 depth 与 parent[k][v]
2. 先让深的节点上跳至同深度
3. 再同时上跳直到父节点相同

## 复杂度

- 预处理: $O(n \log n)$
- 单次查询: $O(\log n)$

## 易错点

- 处理根节点的父亲
- 查询前先对齐深度

## 练习方向

- 路径长度计算
- 树上路径统计
- 结合树形 DP
