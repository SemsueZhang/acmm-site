# 算法基础

本页用于建立算法学习的共同语言与基本习惯，适合刚开始系统训练的同学。

## 学习目标

- 能解释常见时间复杂度与空间复杂度的含义
- 熟悉常见数据结构的基本操作与使用场景
- 形成规范化的解题流程与代码习惯

## 复杂度入门

复杂度描述的是规模增长时的性能变化。

- 时间复杂度: 关注主要操作次数的增长趋势
- 空间复杂度: 关注额外内存的使用趋势

常见量级从小到大:

- $O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$

## 常用数据结构

- 数组与字符串: 基础容器, 适合顺序访问
- 栈与队列: 约束访问顺序, 常用于括号匹配与 BFS
- 哈希表: 以空间换时间, 适合快速查找
- 链表: 便于插入删除, 不适合随机访问

## 解题流程建议

1. 读题: 明确输入输出与限制条件
2. 设计算法: 给出思路并估算复杂度
3. 编码实现: 注意边界与极端情况
4. 验证: 手动构造小样例与反例

## 训练建议

- 每周固定时间训练, 形成节奏
- 解题后写下关键思路与易错点
- 学会总结同类题的通用套路
