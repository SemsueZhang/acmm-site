# 算法学习路线

这里收录 NOIP 提高组所需的主要算法知识。范围以 CCF 发布的[《全国青少年信息学奥林匹克系列竞赛大纲（2025 年修订版）》](https://www.noi.cn/xw/2025-04-18/841584.shtml)中的**入门级与提高级**为准；页面按解题时的知识依赖重新组织，而不是照抄大纲目录。

!!! note "怎样使用这些讲义"
    不要只背模板。建议先遮住代码，独立完成页面中的手算例题，再回答“状态/不变量是什么”“为什么不会漏解”“复杂度为什么能通过”，最后自己重写代码。

## 推荐顺序

1. **基本功**：复杂度、枚举与模拟、排序、二分、前缀和与差分、贪心、分治。
2. **基础结构**：栈、队列、堆、并查集、哈希、ST 表、树状数组、线段树。
3. **搜索与动态规划**：DFS/BFS、剪枝、记忆化、背包、区间 DP、树形 DP、状压 DP。
4. **图与树**：最短路、最小生成树、拓扑排序、欧拉路、二分图、强连通分量、割点割边、LCA 与树上差分。
5. **字符串与数学**：KMP、Trie、字符串哈希、Manacher、数论、组合计数、矩阵与高斯消元。

## 范围说明

- 提高级自动包含入门级，因此前缀和、差分、基础贪心、高精度等也在本站主线中。
- 一个考点可能出现在多个模块中，例如 Trie 同时属于树结构和字符串工具；导航只保留一个主要入口。
- 凸包等计算几何内容在当前大纲中属于 NOI 级，本站以独立拓展章节讲解，不计入 NOIP/CSP-S 主学习路线。
- 题目链接用于课后练习；正文中的“例题”均给出完整建模和可运行实现。

## 做题时的通用检查表

拿到题目后依次问：

1. 数据范围允许 $O(n^2)$、$O(n\log n)$ 还是只能 $O(n)$？
2. 是否存在单调性、前缀可合并性、最优子结构或图结构？
3. 当前做法会不会重复计算？能否预处理、离散化、用数据结构维护？
4. 正确性依赖什么不变量？边界是否覆盖空集、单点、重边、负权和溢出？
