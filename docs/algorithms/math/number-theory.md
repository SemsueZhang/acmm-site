# 初等数论学习路线

数论公式往往很短，但每个公式都有前提。这里不再把筛法、逆元和中国剩余定理挤在同一篇文章中，而按依赖关系拆开学习。

1. [最大公约数与裴蜀定理](gcd-bezout.md)：欧几里得算法、线性组合与扩展欧几里得。
2. [质数、分解与线性筛](prime-sieve.md)：从试除到最小质因子筛。
3. [同余与乘法逆元](modular-inverse.md)：什么时候模意义下可以“做除法”。
4. [中国剩余定理](crt.md)：合并多个同余条件。
5. [快速幂](fast-power.md)：在对数时间内计算模幂。

学习时始终先问三件事：模数是否为质数、待求逆的数是否与模数互质、中间乘积是否会溢出。费马小定理、欧拉定理和逆元都不能脱离这些前提使用。
