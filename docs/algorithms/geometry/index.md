# 计算几何

!!! info "范围说明"
    计算几何在 2025 年竞赛大纲中属于 NOI 级拓展。NOIP/CSP-S 备赛者可以先跳过，不应挤占图论、动态规划和基础数据结构的训练时间。

## 学习顺序

1. [计算几何基础](basics.md)：点、向量、点积、叉积、线段相交和多边形面积。
2. [二维凸包](convex-hull.md)：从方向判断推导 Andrew 单调链，并用凸包求最短包围周长。

## 统一约定

- 整数坐标的方向和面积判断优先使用整数类型，并先估算乘法是否溢出。
- 浮点问题统一使用 `EPS` 与符号函数，不直接比较相等。
- 写代码前明确共线、端点接触和边界点是否计入答案。
- 图解只能帮助观察方向，最终判断必须落实到叉积符号和题目边界。
