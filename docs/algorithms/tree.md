# 树基础

树是连通无环无向图，$n$ 个点恰有 $n-1$ 条边。任选一个点作为根后，每个非根节点都有唯一父亲，图上的无向关系转成层次关系。

## 基本量

- 深度 `depth[u]`：根到 $u$ 的边数。
- 子树：$u$ 及其所有后代。
- 子树大小 `size[u]`：子树顶点数。
- 高度：节点到最深后代的距离。
- 叶子：在有根树中没有孩子的点；注意根只有一个邻居时是否算叶子取决于语境。

## 邻接表 DFS

无向树的邻接表包含父子两个方向，递归时必须排除父亲。

```cpp
void dfs(int u, int parent) {
    size[u] = 1;
    for (int v : g[u]) {
        if (v == parent) continue;
        depth[v] = depth[u] + 1;
        dfs(v, u);
        size[u] += size[v];
    }
}
```

### 例题：求每个节点的子树大小

树边 `1-2,1-3,3-4,3-5`，根为 1。叶子 2、4、5 的大小为 1；3 的大小为 $1+1+1=3$；1 的大小为 $1+1+3=5$。后序时孩子已算完，正好向父亲合并。

## 二叉树遍历

- 前序：根、左、右，适合复制树或输出结构。
- 中序：左、根、右；BST 中序得到有序序列。
- 后序：左、右、根，适合先算孩子再算父亲。
- 层序：BFS 按深度访问。

遍历名称描述的是“根相对左右子树何时被访问”，而不是死记字符串。

## 孩子兄弟表示法

一般树每个节点孩子数不固定。可让 `firstChild[u]` 指向第一个孩子，`nextSibling[v]` 指向同一父亲的下一个孩子，于是每个节点只需两个指针，形式上变成二叉结构。遍历 `u` 的所有孩子时，从 `firstChild[u]` 沿 `nextSibling` 链移动。

## DFS 序

进入节点时记录 `tin[u]=++timer`，遍历完子树后记录 `tout[u]=timer`。则 $u$ 的整棵子树恰对应连续区间 `[tin[u],tout[u]]`。因此子树修改/查询可以转成数组区间问题，再配合树状数组或线段树。

## 易错点

- 把普通图直接当树 DFS，没有判环。
- 无向邻接表遍历不跳父亲，递归来回无限循环。
- 深度和高度混淆。
- 深链上递归栈溢出；可用显式栈记录父亲和遍历顺序，再逆序计算子树信息。
