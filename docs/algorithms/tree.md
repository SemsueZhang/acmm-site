# 树

树是层级结构的典型表示, 常用于组织关系、搜索与区间查询。树的遍历与递归思想紧密相关。

## 基本概念

- 节点, 边, 根, 叶子
- 深度与高度
- 度: 节点子节点数量

## 二叉树

二叉树是最基础的树结构, 每个节点最多有两个子节点。

- 满二叉树, 完全二叉树
- 二叉搜索树(BST): 左子树值 < 根 < 右子树值

## 遍历方式

- 先序遍历: 根 -> 左 -> 右
- 中序遍历: 左 -> 根 -> 右
- 后序遍历: 左 -> 右 -> 根
- 层序遍历: 使用队列, 按层访问

## 常用树结构

- 堆: 完全二叉树, 维护最值
- 线段树: 处理区间查询与区间更新
- 树状数组: 前缀和与区间加减

## 常见题型

- 最近公共祖先(LCA)
- 子树大小与树形 DP
- 维护动态区间信息

## 训练建议

- 先熟练写出递归与非递归遍历
- 理解树与数组的映射关系
- 练习区间数据结构与查询
