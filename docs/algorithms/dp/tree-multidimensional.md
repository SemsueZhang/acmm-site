# 多维与树形 DP

## 多维 DP：多一个影响未来的条件

状态增加维度不是为了“显得高级”，而是因为仅凭原状态无法决定未来。维度可能表示剩余次数、上一动作、两个序列位置等。

### 例题：最长公共子序列（LCS）

给定字符串 $A,B$，求最长公共子序列长度。定义 `dp[i][j]` 为 $A$ 前 $i$ 个字符与 $B$ 前 $j$ 个字符的答案。

- 若 `A[i-1]==B[j-1]`，可把这个公共字符接到两段前缀的答案后：`dp[i][j]=dp[i-1][j-1]+1`。
- 否则最后不同时使用这两个字符，至少舍弃一个：`max(dp[i-1][j],dp[i][j-1])`。

```cpp
vector<vector<int>> dp(n + 1, vector<int>(m + 1));
for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        if (a[i - 1] == b[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
        else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
    }
}
```

`abcde` 与 `ace` 的答案为 3。时间、空间 $O(nm)$；因为第 $i$ 行只依赖前一行和本行左侧，可滚动为 $O(m)$ 空间。

## 树形 DP

树形 DP 先由孩子计算父亲。状态通常以“以 $u$ 为根的子树，并规定 $u$ 的选择状态”为含义。

### 例题：树的最大权独立集

选择若干点，使相邻点不能同时选，最大化权值和。

- `dp[u][0]`：$u$ 不选时，其子树最大权值。
- `dp[u][1]`：$u$ 选择时，其子树最大权值。

对每个孩子 $v$：

$$
dp[u][0] += \max(dp[v][0],dp[v][1]),
$$

$$
dp[u][1] += dp[v][0].
$$

```cpp
void dfs(int u, int p) {
    dp[u][0] = 0;
    dp[u][1] = weight[u];
    for (int v : g[u]) if (v != p) {
        dfs(v, u);
        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
}
```

例：中心点权值 5，三个叶子各 2。选中心得 5，不选中心可选三个叶子得 6，所以答案 6。

每条边访问常数次，时间 $O(n)$。

## 树上背包

若状态还记录子树中选了几个点，`dp[u][k]` 在合并孩子时需要枚举当前已选数和孩子贡献数，类似把每棵孩子子树当成一组物品。合并前必须保存旧值或倒序枚举，避免同一个孩子被使用多次。

## 换根 DP 的直觉

若要求“以每个点为根”的答案，可先从固定根求子树信息，再在第二次 DFS 中把父亲侧贡献传给孩子。总答案被拆成孩子侧与父亲侧，换根时只改变跨过一条边的归属。

## 易错点

- 多维状态少了一维关键历史信息，转移看似能写但不正确。
- 滚动数组后遍历方向破坏依赖。
- 树形 DP 没跳父亲，或父亲参数与有向孩子表混用。
- 合并孩子时原地正序更新，让同一孩子重复贡献。
- 最终答案忘记对根的不同状态取最值。
