# 图

图是描述多对多关系的结构, 常用于网络、路径与依赖关系建模。

## 基本概念

- 顶点与边
- 无向图与有向图
- 权值与带权图
- 连通分量与强连通分量

## 存储方式

- 邻接表: 适合稀疏图, 访问边高效
- 邻接矩阵: 适合稠密图, 访问边 $O(1)$

## 基本遍历

- DFS: 递归或显式栈, 适合连通性与拓扑判断
- BFS: 使用队列, 适合最短路(无权图)

## 典型算法

- 最短路: Dijkstra, Bellman-Ford, Floyd
- 最小生成树: Prim, Kruskal
- 拓扑排序: 有向无环图中的任务排序

## 常见题型

- 连通性判断与分量计数
- 图上的最短路径与路径重构
- 有向图环检测

## 训练建议

- 熟悉 DFS/BFS 模板与边界处理
- 先掌握无权图最短路, 再学习带权图
- 练习并查集在图中的应用
